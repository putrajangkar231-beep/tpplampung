# TPP Lampung

**Media dan Informasi Pendampingan Masyarakat Desa**

TPP Lampung adalah proyek portal berita dan informasi mengenai pendampingan masyarakat desa serta pembangunan desa di Provinsi Lampung.

## Tujuan

- Menyajikan berita dan informasi desa.
- Menyediakan informasi pendampingan masyarakat desa.
- Menjadi portal informasi yang mudah digunakan dan dikembangkan.

## Teknologi

Proyek ini akan dikembangkan secara bertahap menggunakan teknologi web standar.
